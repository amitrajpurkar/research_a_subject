## Why learn Pandas?
- Pandas is a powerful data manipulation library for Python
- It provides data structures and functions designed to work with structured data
- It's widely used in data science, machine learning, and data analysis
- It's built on top of NumPy and integrates well with other scientific computing libraries

## Drivers in todays era
- Data is everywhere and growing exponentially
- most of us have been working with SQL and a variety of databases: Oracle, SQL Server, IBM DB2, MySQL, PostgreSQL, MongoDB, etc.
- we need to port our SQL skills to Python and Pandas as well
- data is now in Snowflake, Databricks, etc. it is on Cloud Platforms: AWS, Azure, GCP
- Data needs to be processed, analyzed, and visualized
- Pandas provides a powerful and flexible way to do this

## What to learn?
- Data structures: Series and DataFrame
- Data manipulation: filtering, sorting, grouping, merging
- Data cleaning: handling missing data, duplicates, outliers
- Data analysis: descriptive statistics, correlation, regression
- Data visualization: plotting with matplotlib and seaborn
- Data I/O: reading and writing data from various formats (CSV, Excel, JSON, SQL, etc.)
